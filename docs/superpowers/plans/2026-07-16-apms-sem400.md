# APMS SEM400 Option Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow APMS rainfall calibration to use either `TB-400-04` or `SEM400` while retaining the legacy `RK400-04` compatibility alias.

**Architecture:** Keep validation database-driven through `logger_modes.calibration_fields`. Update clean-install definitions and add an additive corrective migration for deployed databases; the existing runtime normalizer continues to translate only `RK400-04` into `TB-400-04`.

**Tech Stack:** PHP 8.2, Laravel 12, Pest 3, React 19, TypeScript 5, Vite 7

## Global Constraints

- APMS `arr_sensor` options are exactly `TB-400-04` and `SEM400`.
- ARR options remain exactly `TB-400-04` and `SEM400`.
- `SEM400` is forwarded unchanged to MQTT.
- Legacy `RK400-04` continues to normalize to `TB-400-04`.
- Unsupported APMS sensor names remain invalid.
- No Flutter or `mobile_cloud/` file changes.

- [ ] **Step 5: Add the corrective production migration**

Create `database/migrations/2026_07_16_000003_add_sem400_to_apms.php`:

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Support\Facades\DB;

return new class extends Migration
{
    public function up(): void
    {
        $this->setOptions([
            ['value' => 'TB-400-04', 'label' => 'TB-400-04'],
            ['value' => 'SEM400', 'label' => 'SEM400'],
        ]);
    }

    public function down(): void
    {
        $this->setOptions([
            ['value' => 'TB-400-04', 'label' => 'TB-400-04'],
        ]);
    }

    private function setOptions(array $options): void
    {
        $mode = DB::table('logger_modes')->where('slug', 'APMS')->first();
        if ($mode === null) {
            return;
        }

        $fields = json_decode($mode->calibration_fields, true);
        if (! is_array($fields)) {
            return;
        }

        foreach ($fields as &$field) {
            if (($field['key'] ?? null) === 'arr_sensor') {
                $field['options'] = $options;
                break;
            }
        }
        unset($field);

        DB::table('logger_modes')->where('slug', 'APMS')->update([
            'calibration_fields' => json_encode($fields),
            'updated_at' => now(),
        ]);
    }
};
```
